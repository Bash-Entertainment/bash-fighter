# CLA Signatures

This file is the record of who has agreed to the Bash Fighter Contributor
Licence Agreement ([CLA.md](./CLA.md)). The `CLA Check` GitHub Actions
workflow reads this file to decide whether a pull request's author has
signed.

**If you are opening your first pull request:** add one line to the end
of the list below, in your own PR, with your exact GitHub username:

```
- @your-github-username: I have read and agree to the Bash Fighter CLA (CLA.md).
```

Do this once. It covers all your future contributions — you don't need
to add it again on later PRs.
